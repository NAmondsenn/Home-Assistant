# Exact versions of every package Nova's brain needs - backend.py, in its own container
# on PVE2 (Debian 13, Python 3.13) - see docs/decisions/0006. It's everything but
# the satellite's microphone, speaker and wake word: Claude, Spotify, Home Assistant's
# MQTT, Nemotron, and openWakeWord (for its Silero voice activity check only). The
# versions are those in the satellite's requirements.lock before it was trimmed, which
# the whole of Nova was tested with on the Pi, except sherpa-onnx.
#
# Install it without dependency resolution, since it already lists everything -
# resolving would pull in openwakeword's tflite-runtime, which has no wheels for
# Python 3.12+:
#   venv/bin/pip install --no-deps -r requirements-backend.txt
# scipy, scikit-learn, joblib, threadpoolctl, cloudpickle and narwhals are there because importing openwakeword
# at all imports its custom-verifier trainer, which needs them, though Nova never trains
# one. They were in the first lock (19 October) and dropped with librosa on 20 October,
# which left a fresh install from it unable to import openwakeword (the Pi's existing
# venv kept them, so it didn't show). Re-added at the versions pip chose on the Pi on
# 22 October 2026, checked by importing openwakeword in a fresh venv.
